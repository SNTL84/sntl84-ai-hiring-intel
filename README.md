## 🚀 Core Features

### 📋 Intelligent Resume Screening
- Upload job description → AI extracts required skills, experience, and culture signals
- Upload candidate resumes (PDF/text) → scored and ranked automatically
- Match % per candidate with **reasoning**, not just a number

### 🏆 Candidate Ranking Dashboard
- Side-by-side comparison view
- Filter by score threshold, skills gap, experience band
- Export shortlist as CSV or printable report

### 🔎 Skill Gap Analysis
- Instantly see what each candidate is missing vs. your JD
- Highlight "fast learner" signals from career trajectory

### 📊 Hiring Velocity Tracker
- Track time-to-screen, time-to-shortlist, time-to-offer
- Benchmark across open roles — know where your pipeline slows

### 🔗 API-First Architecture
- REST API in `/api/` — plug into your existing ATS or Notion workflow
- Vercel-ready deployment in under 5 minutes

## ⚙️ Quick Start (Self-Hosted)

```bash
# 1. Clone the repo
git clone https://github.com/SNTL84/sntl84-ai-hiring-intel.git
cd sntl84-ai-hiring-intel

# 2. Install dependencies
npm install

# 3. Add your OpenAI API key
echo "OPENAI_API_KEY=your_key_here" > .env

# 4. Run locally
node app.js
# → Visit http://localhost:3000
```
